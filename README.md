# Homebrew tap cho Shotmesh

```bash
brew install --cask khiemk31/tap/shotmesh
```

Cập nhật lên bản mới:

```bash
brew update && brew upgrade --cask shotmesh
```

Xoá sạch (kèm cả dữ liệu app):

```bash
brew uninstall --zap --cask shotmesh
```

File cài đặt được host ở [khiemk31/shotmesh-releases](https://github.com/khiemk31/shotmesh-releases/releases).
